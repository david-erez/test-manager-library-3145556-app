# test-manager-library-3145556-app
> **Technical assessment · ADSO record 3145556**
> Deadline: **Tuesday, October 13, 2026, at 5:00 p.m.** (17:00, Colombia time).
This repository contains the **React frontend** for *Manager Library*. It **starts empty on purpose**: each trainee builds it in their own fork.
## Instructions
Each trainee must **fork all six project repositories** and **build the project from the provided specification**.
1. Fork each repository in the table below to your GitHub account.
2. Read the specification in [`test-manager-library-3145556-docs`](https://github.com/code-sena/test-manager-library-3145556-docs).
   It is provided in two versions: `spec-python/` and `spec-.net/`.
3. Develop your solution in your forks.
## The challenge uses React and PHP (Laravel)
The specification is written for Python and .NET, but the challenge **does not** use those languages:
| Layer | Challenge technology |
|---|---|
| Frontend | React |
| Backend | PHP with Laravel |
Follow the business requirements in the specification—user stories, acceptance criteria, business rules, API contract, and data model. Adapt its technology-specific decisions to React and Laravel.
## The assessment is about more than writing code
The main goal is to evaluate your **ability to work with SDD** (*Spec-Driven Development*): how you read, interpret, and apply a specification when moving it to a different technology stack. Code is the means, not the end.
## Submission
Only work **pushed to your forks by 5:00 p.m.** (17:00) will be reviewed. Late work will not be reviewed. There are no extensions: push partial progress in small commits throughout the assessment.
